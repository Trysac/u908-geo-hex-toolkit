# trysac-geo-hex-toolkit

[![CI](https://github.com/Trysac/u908-geo-hex-toolkit/actions/workflows/ci.yml/badge.svg)](https://github.com/Trysac/u908-geo-hex-toolkit/actions/workflows/ci.yml)

Pure Python hierarchical hexagon grid on an equal-area projection with exact integer parent and child links, great-circle distances and polygon cover.

> **Notice**: The grid generated by this library is **not** H3-compatible. Cell identifiers are independent 64-bit integer values and cannot be compared to or interchanged with H3 indexes.

## Usage

```python
from geo_hex_toolkit import latlng_to_cell, cell_to_string, cell_children, grid_disk

cell = latlng_to_cell(40.4168, -3.7038, 9)
print(cell_to_string(cell))
children = cell_children(cell)
print(f"7 children at res 10: {len(children)}")
neighbors = grid_disk(cell, 1)
print(f"Disk k=1 contains {len(neighbors)} cells")
```

## Features

- **Equal-area cells**: Built on the Lambert cylindrical equal-area projection with authalic sphere radius $R = 6371007.180918475\text{ m}$.
- **Aperture-7 Hierarchy**: Exact integer parent and child relationships across resolutions 0 to 15.
- **Zero runtime dependencies**: Pure standard library implementation.
- **Spatial operations**: Hexagonal grid disk generation, grid distances, Haversine spherical distance, and polygon filling via ray-casting.
